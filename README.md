# Table Tennis Skills Battle

育てろ、君だけの戦型。

Table Tennis Skills Battle は、卓球の戦型・スキルカード・育成方針を組み合わせて勝利を目指す、ブラウザ向け卓球育成オートバトルゲームです。

## 公開URL

https://TetsuroFuture.github.io/TableTennisSkillBattle/

## 遊び方

1. 選手名を入力する
2. 9つの戦型から1つを選ぶ
3. 育成でステータスを強化する
4. スキルカードを装備する
5. CPU対戦や全国Rate対戦に挑む
6. 試合後分析を見て、スキル構成や作戦を調整する

## 戦型

以下の9戦型から選択できます。

- 前陣速攻型
- オールフォア型
- パワー両ハンド型
- ブロック＆カウンター型
- 一撃カウンター型
- オールラウンド型
- ペン粒型
- カットマン型
- 異質攻守型

戦型ごとに得意なステータスや相性が異なります。

## スキルカード

プレリリース版では、スキルカードは最初から全種類使用できます。

ただし、装備できる枚数はレベルに応じて増えます。

- Lv1〜4：2枠
- Lv5〜9：3枠
- Lv10〜19：4枠
- Lv20〜：5枠

## 育成

戦型ごとにステータス上限があります。

自分の戦型に合った育成を進め、基礎能力を完成させましょう。

育成が一段落したら、スキル構成と作戦選択でRate戦に挑みます。

## 全国Rate対戦

育てた選手で全国Rate対戦に挑戦できます。

プレリリース版では、50戦で正式Rateに到達します。

Rate戦では、以下の要素が勝敗に影響します。

- 育成による基本戦力差
- 戦型相性
- スキル効果
- 作戦選択
- 11点先取の試合展開

## 試合後分析

試合終了後、以下を確認できます。

- 試合の流れ
- 勝因 / 敗因
- 次の一手
- 優勢度内訳

負けた場合も、スキル構成や作戦を見直すことで次の試合につなげられます。

## X共有

試合結果画面から、Xで結果を共有できます。

共有文には以下が含まれます。

- 戦型
- 勝敗
- スコア
- Rate変動
- 試合後分析コメント

## プレリリース版について

このゲームはプレリリース版です。

以下の点にご注意ください。

- 仕様やバランスは今後変更される可能性があります
- データ保存にはFirebaseを使用しています
- 簡易ログイン方式のため、他サービスと同じパスワードは使用しないでください

- 不適切な選手名は使用しないでください。運営判断によりデータ削除等を行う場合があります。
